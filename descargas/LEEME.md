# Descargas

`ESE_Control_Setup.exe` — instalador de Windows 10/11 (64 bits) de la herramienta de control. Lleva su propio
Python; no necesita internet ni administrador. Incluye solo datos de demostración **ficticios** (opcionales).

Instrucciones: ver el `README.md` de la raíz y el `LEEME_PRIMERO.txt` que se instala con el programa.
Se regenera con `python scripts/crear_instalador.py` (requiere `apt install nsis`).

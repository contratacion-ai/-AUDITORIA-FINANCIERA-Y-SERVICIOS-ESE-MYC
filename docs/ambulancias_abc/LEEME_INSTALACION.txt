COSTEO ABC AMBULANCIAS - ESE MORENO Y CLAVIJO
==============================================

Este instalador convierte ESTE equipo en el servidor de la aplicación.
Los demás equipos de la red solo necesitan un navegador.

No se pide usuario ni contraseña. Al iniciar elija:
  - "Para todos los usuarios": Windows pide confirmar el permiso de administrador;
    el servidor queda disponible para toda la red.
  - "Solo para mí": no pide credenciales; funciona en este equipo. Para abrirlo a la
    red, un administrador ejecuta luego "Habilitar acceso desde la red".

El usuario "admin" de la aplicación se crea con una clave aleatoria que se muestra
al terminar (archivo CREDENCIALES_ADMIN.txt). Cámbiela al ingresar.

Qué hace el instalador:
  - Instala Python embebido y la aplicación en C:\Program Files\CosteoABCAmbulancias
  - Crea la base de datos centralizada (C:\ProgramData\CosteoABCAmbulancias)
  - Carga la flota, los perfiles del informe técnico y las tarifas 2026 (Anexo 3)
  - Abre el puerto elegido en el firewall (redes de dominio y privadas)
  - Programa el servidor al iniciar Windows y un respaldo diario a las 23:00

Después de instalar, desde cualquier equipo de la red abra:
  http://NOMBRE-DE-ESTE-EQUIPO:8090/
(si el 8090 lo usa otra aplicación, por ejemplo la de auditoría de facturación,
el instalador toma el siguiente puerto libre; use el acceso directo del escritorio
o la dirección que indica CREDENCIALES_ADMIN.txt)

Documentación completa: carpeta "docs" del programa
  INSTALACION.md        instalación, usuarios, respaldo y restauración
  GUIA_CARGAS_MENSUALES.md  facturación, RIPS (traslados y APH), consumos y recorridos por sede
  MODELO_DATOS.md       fórmulas ABC, drivers y modelo de datos
  INTEGRACION.md        intercambio con las aplicaciones de RIPS y auditoría
  CALIDAD_DATOS.md      inconsistencias detectadas en las fuentes
  DECISIONES_TECNICAS.md

Desinstalar no borra la base de datos ni los respaldos.

CONTROL ESE MORENO Y CLAVIJO - Servicios publicos, combustible y mantenimientos
================================================================================

ABRIR LA APLICACION
  Use el acceso directo "Control ESE Moreno y Clavijo" del escritorio. Se abre una ventana negra
  (NO la cierre mientras use la aplicacion) y el navegador en http://localhost:8501

  Si instalo los datos de demostracion (cifras ficticias):
     admin  / Demo2026*    area central: ve toda la ESE, catalogo, usuarios
     fortul / Demo2026*    usuario de sede: solo el Hospital de Fortul
  Si NO los instalo, al abrir por primera vez la aplicacion pide crear el usuario central.

QUE CARGA
  Solo los archivos de: energia, acueducto, combustible del parque automotor, combustible de plantas
  electricas, desplazamientos y mantenimientos (o las plantillas del menu Plantillas).

ANTES DE CARGAR DATOS REALES
  1. En el menu Catalogo suba el catalogo de sedes, codigos y placas. Sin el, las filas se rechazan
     con el motivo "sede no reconocida".
  2. Si instalo la demostracion, cambie las contrasenas o cree usuarios nuevos en Administracion, y
     borre la base de prueba (desinstale y conteste NO a conservar datos, o borre la carpeta datos).

DONDE QUEDAN LOS DATOS
  %LOCALAPPDATA%\ControlESE\datos   (haga copia de seguridad de esta carpeta)

SI ALGO FALLA
  - "las librerias no cargan": instale https://aka.ms/vs/17/release/vc_redist.x64.exe
  - El antivirus bloquea python.exe: es el Python oficial; permita la carpeta ControlESE.
  - Puerto ocupado: cierre otra ventana de la aplicacion y vuelva a abrirla.

ACTUALIZAR: ejecute el Setup nuevo; el programa se actualiza y los datos se conservan.
DESINSTALAR: Configuracion de Windows > Aplicaciones, o el acceso "Desinstalar" del menu Inicio.
Use la aplicacion solo dentro de la red interna de la ESE (no hay cifrado HTTPS).
